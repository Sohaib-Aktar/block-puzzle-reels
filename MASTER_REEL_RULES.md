# MASTER REEL GENERATION INSTRUCTION

Before generating any Reel, ALWAYS read and follow MASTER_REEL_RULES.md.

These rules are permanent and apply to all 30 days of the block puzzle marketing campaign.

## Workflow for every new Reel

1. Read the permanent Reel generation rules.
2. Read the new day's creative brief.
3. Understand the marketing objective.
4. Analyze the uploaded gameplay recording.
5. Identify the most relevant real gameplay moments.
6. Prepare an editing timeline with timestamps.
7. Select suitable hooks, captions, transitions and audio.
8. Generate the video using FFmpeg and local processing wherever possible.
9. Preview the rendered output.
10. Run the complete quality-control checklist.
11. Export the final MP4.

## Strict instructions

- English is the ONLY language allowed for on-screen text.
- Preserve the original gameplay.
- Never fabricate gameplay or game features.
- Never reuse the same creative concept without a reason.
- Follow the duration specified in each day's brief.
- Do not introduce unnecessary effects.
- Do not automatically change the game's visual identity.
- Do not use paid AI video generation when ordinary editing can achieve the result.
- Do not publish automatically. Generate the final video for manual approval.

## Daily brief priority

The day's creative brief determines:
- Topic
- Marketing objective
- Hook
- Required shots
- Duration
- Caption
- Special editing instructions

The permanent rules determine everything else.

If the creative brief conflicts with the permanent rules, preserve the permanent rules unless the user explicitly changes them.

## Deliverables

For each day, save:

- Day_XX_Final.mp4
- Day_XX_Caption.txt
- Day_XX_Editing_Plan.txt

Maintain a separate folder for each day's original recording, editing plan and final export.

Never overwrite an approved Reel without confirmation.
