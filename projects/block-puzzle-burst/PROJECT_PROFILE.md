## Key gameplay mechanics (verified from recordings)
- 10×10 grid board
- Three piece tray (3 pieces at a time, labelled A/B/C for challenge videos)
- Clear complete rows and columns for points
- Combo multiplier: chain clears → x2, x4, x6, x8+
- Score card with QR code (shareable via WhatsApp)
- No timer (relaxed gameplay)
- Offline mode (airplane mode works)
